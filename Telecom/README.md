# Telecom Loan Repayment Prediction using Machine Learning

## Overview

This project explores Machine Learning classification techniques to predict loan repayment behaviour using telecom-related customer data.

The objective is to identify customers who are likely to repay their loans and those who may become delinquent.

## Project Workflow

1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature engineering
5. Training and testing data preparation
6. Classification model development
7. Model evaluation and comparison

## Model Evaluation

The project explores classification performance using metrics such as:

- Log Loss
- Precision
- Recall

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
