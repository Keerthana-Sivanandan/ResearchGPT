# Machine Learning Projects

This repository contains Machine Learning projects developed to explore real-world datasets, understand data patterns, and build predictive models.

## Projects

### 1. House Price Prediction

A regression-based Machine Learning project that predicts house prices using property-related features.

**Key activities:**
- Exploratory Data Analysis
- Data cleaning and preprocessing
- Handling missing values and categorical variables
- Feature engineering
- Training and comparing regression models

**Models explored:**
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

**Evaluation metrics:** MAE, RMSE and R² Score.

[Explore House Price Prediction](./House-Price-Prediction/)

### 2. Telecom Loan Repayment Prediction

A classification-based Machine Learning project focused on predicting loan repayment behaviour using telecom-related data.

**Key activities:**
- Data preprocessing
- Exploratory Data Analysis
- Feature engineering
- Classification model development
- Model evaluation

[Explore Telecom Loan Repayment Prediction](./Telecom-Loan-Repayment/)
